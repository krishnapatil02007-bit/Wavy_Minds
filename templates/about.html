🤖 ML Anomaly Detection

  • Model: Isolation Forest (Unsupervised Learning)
  • Why: Detects deviations without needing labeled "unsafe" data.
  • Features: pH, TDS, Turbidity, Temperature.
  • Training Data: Synthetic dataset based on BIS Drinking Water Standards.

⚡ IoT Architecture

Backend: Flask (Python) handles API requests and ML processing.
Simulation: Modular Python script mimics ESP32 JSON payloads.
Frontend: Bootstrap 5 Dashboard with AJAX polling.
